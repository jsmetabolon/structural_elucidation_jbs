# Report Presentation & Evidence-Gap Findings

Audit of all **3,897** X-compound HTML reports for scientific completeness and
presentation quality, with each gap mapped to a concrete pipeline refinement.
Generated by `tools/audit_presentation.py` (per-report CSV + summary JSON + gap
gallery under `output/_presentation_audit/`). Evidence is drawn from the report
sidecars enriched with the `report_data_bundle` (observed m/z, observed MS2,
pipeline spectral scores) via `tools/enrich_report_evidence.py`.

## Headline: the overall confidence was overstated and is now honest

Before, reports had no single overall confidence; the header implied high
confidence via "Exact reference match" / a nearest-reference Tanimoto badge. But
on the 92 controls with a known true structure, an **exact catalog match is
correct only ~38%** of the time (median truth Tanimoto 0.51) - essentially the
same as de novo predictions (~56%). "Exact reference match" therefore is a
factual descriptor, not high confidence.

The redesigned confidence (`structural_elucidation/reports/confidence.py`) is a
calibrated estimate of P(top structure correct) combining four evidence axes
(structure 0.40, mass 0.30, MS2 0.20, pathway 0.10), Platt-scaled on the 92
truth-verified controls, with a corroboration-aware, monotonic tier. Result:

- Tier distribution: **Moderate 1,440 / Low 1,361 / Tentative 1,096 / High 0.**
- Overall confidence: median **0.43** (p10 0.37, p90 0.59).
- No compound is labeled "High" - with no authentic-standard confirmation and
  MS2 present for <=44%, nothing is confidently confirmable yet. This is honest
  by design and directly answers "the confidence looks too high / should be revised."

## Prioritized scientific gaps -> pipeline refinements

### 1. Co-abundance correlations are 100% placeholder (highest impact)
`correlations_real = 0%`: every "Top Correlating Metabolites" table uses proxy
nearest-structural-neighbors, not measured co-abundance. Refinement: wire the
real WGCNA / co-abundance correlation matrix (per dataset) into report
generation; correlations to known metabolites are strong orthogonal ID evidence
and would add a genuinely independent confidence axis.

### 2. Display name / synonyms unresolved for ~60%
`name_is_control_id = 60.5%`, `synonyms_empty = 60.6%`: novel predicted
structures have no reference-DB name. Refinement: expand InChIKey-skeleton and
name resolution against a larger metabolite/chemistry catalog (PubChem/ChemIDplus
offline), and surface a systematic name when no trivial name exists.

### 3. MS2 spectra present for only 44%; used by the model but sparse
`ms2_spectrum_present = 43.6%`. MS2 is the strongest independent corroboration,
so absence caps confidence. Refinement: ensure observed MS2 is captured/propagated
for all features with a spectrum, and improve the candidate-vs-spectrum scorer
(the report's raw-m/z matcher could not consume the binned lookups; the pipeline
`predicted_spectrum_score_v2` was used instead). Observed MS2 ions remain
**internal-only** by policy.

### 4. Observed parent m/z missing for ~37%
`observed_mz_available = 63.4%` (was ~15% before this work). Refinement:
propagate observed parent m/z + adduct for every control from feature rows into
the rerank outputs so mass error is always computable and displayed.

### 5. Top candidate mass mismatch for 15%
`mass_mismatch = 15.3%`: the rank-1 candidate's formula/mass disagrees with the
observed neutral mass (e.g. X-12811, a glucuronide 176 Da heavier than the
feature). These are now demoted to Tentative with a red-flag caveat. Refinement:
add a hard mass/formula gate in reranking so a candidate that fails the observed
mass cannot take rank 1.

### 6. No authentic-standard / Level-1 confirmation signal
Nothing reaches "High". Refinement: capture Metabolon identification Level /
authentic-standard matches where they exist and feed them as a top-tier axis so
confirmed IDs can legitimately reach High.

## Compliance

Public reports must not contain observed MS2 ions. Audit confirms
**`public_ms2_leaks = 0`**: the MS2 axis, ion counts, and observed-spectrum
detail appear only in the internal variant; the single overall confidence (which
uses MS2 where available) appears in both. Parent (MS1) m/z remains in public.

## Limitations

- Confidence is calibrated on **92** structure-verified controls (the complete
  local truth set); absolute probabilities are approximate and the model is
  intentionally conservative. Expanding the validated control set (gap #6) is the
  single best way to sharpen calibration.
- `mass_nan_public = 0` and observed m/z now render where available; the ~37%
  still missing are a data-propagation gap (#4), not a rendering bug.
