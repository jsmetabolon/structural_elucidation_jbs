# Manuscript: Evidence-Calibrated Structural Elucidation and Pathway Assignment

This folder holds the publication draft and its figures.

- `manuscript.md` - the full manuscript (Abstract, Introduction, Methods/Workflow, Results, Discussion, Limitations, Conclusion, References). All numbers are produced by the audit tooling and are reproducible.
- `figures/` - vector (SVG) figures, generated by `tools/paper_figures.py` from the audit JSONs.

## Regenerate the figures

```bash
python3 tools/paper_figures.py \
  _audit_pull/reports/audit_pathway_summary.json \
  output/_presentation_audit/audit_presentation_summary.json
```

## Reproduce the underlying numbers

```bash
python3 tools/audit_pathway_predictions.py --equalization-root output/pipeline_equalization --loo
python3 tools/audit_presentation.py _audit_pull/reports --out-dir output/_presentation_audit
```

## Build a PDF / Word document

The manuscript is Markdown so it renders directly on GitHub. To produce a submission PDF or DOCX (requires `pandoc`, and a LaTeX engine for PDF - not installed in the report VM):

```bash
# PDF (needs a TeX engine, e.g. tectonic or texlive)
pandoc docs/paper/manuscript.md -o manuscript.pdf --pdf-engine=tectonic --resource-path=docs/paper

# Word
pandoc docs/paper/manuscript.md -o manuscript.docx --resource-path=docs/paper
```

SVG figures embed directly in HTML/GitHub; for PDF via some engines you may first rasterize them (e.g. `rsvg-convert -f pdf`).
